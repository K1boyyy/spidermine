# 🕷️ SPIDERMINE — Virtual Gift

Website virtual gift anniversary untuk pacar.

## Isi website
1. Anniversary date lock — kode `220224`
2. "Do you love me?" + 404 joke
3. Love letter
4. Music/memory page
5. Catch the Hearts mini-game
6. Final photo + closing message

## Cara memasukkan foto
Masukkan foto kalian ke:

`images/us.jpg`

Kalau nama file berbeda, ubah bagian ini di `index.html`:

`src="images/us.jpg"`

## Cara memasukkan musik
Masukkan file audio yang kamu punya hak untuk digunakan ke:

`music/our-song.mp3`

Jangan upload lagu berhak cipta ke repository kalau kamu tidak punya izin untuk mendistribusikannya.

## GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua isi folder ini.
3. Masuk Settings → Pages.
4. Pilih Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. Tunggu GitHub Pages membuat link website.

## Catatan
Placeholder Spider-Man/MJ di love-letter dibuat sebagai elemen dekoratif sederhana. Kalau kamu punya gambar yang ingin dipakai, kamu bisa memasukkannya sendiri ke folder `images` dan nanti kode bisa diarahkan ke file tersebut.
